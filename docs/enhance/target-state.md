# MathModelAgent 最终目标

## 成功定义

给定赛题和附件，稳定产出完整、可复现的 `res.md` 和 `res.docx`；任务不得把失败阶段伪装为成功。

## 最终流水线

题目事实 -> 建模方案 -> 可执行求解 -> 可验证结果包 -> 论文 -> 导出校验

## 不变量

- 每个阶段有明确输入、输出、失败状态和验收证据。
- 下游只读取结构化交接物，不读取上游闲聊。
- 所有 E2E 对比固定代码版本、模型配置和 fixture。
- 成功率优先于 token、调用数或局部耗时。

## 性能目标

只统计成功任务的 P50/P90 墙钟时间；失败任务不视为高效。

## 非目标

当前阶段不优化论文样式、图表模板、Coder ReAct 或并发。
